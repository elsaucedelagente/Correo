# Correo

## Correos favoritos (RF-09)

Usá `marcarComoFavorito()` y `desmarcarComoFavorito()` para actualizar un correo.
`buzon.favoritos()` consulta favoritos de todas las bandejas activas; acepta
un predicado para combinar condiciones, por ejemplo `buzon.favoritos(noLeido)`.
Los correos en Eliminados no aparecen hasta ser restaurados.
